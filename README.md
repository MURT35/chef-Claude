# chef-Claude:-
is a recipe generator app that turns the ingredients you already have into a ready to cook recipe.

#how it works:-
1. Add ingredients : Type an ingredient (for example , pasta) and click Add Ingredient , Each one is added to your Ingredients on Hands list.
2. Reach four ingredients: the get a recipe button stays hidden until you have at least four ingredients . Once you do , a Ready for a recipe ? prompt appears and asks you to generate a recipe from that list.
3.Ask the AI. Click Get a recipe. Chef Claude sends your ingredients to an AI and asks for a recipe you can make with them. The button changes to Getting recipe... while it writes, so you cannot start a second request at the same time.
4. Read the result. The recipe appears under Chef Claude Recommends, formatted with a short introduction, a title, an ingredients list, and numbered instructions. The AI does not have to use every ingredient, and it may add a few common extras (such as salt, oil, or water) when the dish needs them.

If something goes wrong — a missing token, a failed request, or an empty reply — the app shows an error instead of a recipe, and you can try again.
